# Portfolio

Personal portfolio website built with Next.js and React.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint

## Getting Started

### Prerequisites

- Node.js 18+ (recommended: latest LTS)
- npm

### Install

```bash
npm install
```

### Run in development

```bash
npm run dev
```

Open `http://localhost:3000`.

## Production

Build:

```bash
npm run build
```

Start:

```bash
npm run start
```

## Lint

```bash
npm run lint
```
